# 待核验与覆盖范围

- 社区候选点的正式版位置、可进入性、分店名称与入口需要游戏画面对照。地图默认隐藏该图层。
- 首版未发布精确位置。扩大精确点位需要带地图缩放与 UI 参照的首发版实机素材，以及社区底图局部位置的独立复核。
- 首章与第二章任务索引目前收录部分已确认标题。触发点、奖励、可错过条件和多数详细步骤仍待逐项补齐，后续章节和支线覆盖也待扩展。
- 载具、武器、秘籍和各种收集品未全量录入。未核验的武器、车辆数值及按键保持缺省。
- 竞速金牌、店铺项目和带标记钞票阈值需要同平台游戏菜单画面处理差异。首章居所冥想对专属奖杯的影响需复测。
- 社区地图不用于计算驾驶导航。不具备从主机读取位置、游戏存档或账号同步的接入。
- 离线包含首次加载成功的基础底图、文本资料和近期缓存的瓦片。外链媒体需要联网。Playwright 使用设备模拟配置，仍需要实体设备体验验证。
