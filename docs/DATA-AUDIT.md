## 审核口径

- **官方确认**用于 Rockstar 页面与海报能确认的事实。社区坐标单列为大致区域。
- **实机核验**用于有可追溯实机图或第一手实机攻略的条目，特指可核对公开游戏证据，本站未接入主机。
- **多来源核验**要求公开来源不同，可核对相关字段。媒体转述同一源不追加独立票数。同一条目的独立核验范围在来源说明中标注。
- **社区待核验**目前主要包括 GTADB 命名地点，默认隐藏。
- **存在争议**用于同一规则出现不同阈值的情形，保留原始记录与来源，等待游戏内统计界面对照。

## 坐标与覆盖

底图输入 WebP 为 10,000 × 10,000，构建裁切到 7,500 × 9,504 后生成 256 × 256 瓦片，并提供总览。GTADB 原始世界网格到裁切后图像的转换为 `X = 5500 + 0.5x`、`Y = 5504 - 0.5y`。Leaflet CRS.Simple 在 z5 使用图像单位。海报参考点位由预览海报与社区地图的岸线、机场和内湖进行目视配准，只有区域精度。抽查罪恶城国际机场、西南零英里航空站、雷奥奈达湖与伦托岛的相对位置，落在各自相应的跑道、湖岸或岛链区域。社区坐标未使用现实世界 GPS。

发行版可探索范围以整张经授权社区底图为覆盖边界，社区重建不能证明每一条道路或新地标与官方首发版相符。已核验的文字资料可独立可查，坐标无法对照的条目只进入列表。

## 已发现问题

- 社区快照有重复建筑、未定名记录、同名分店和发售前内容。正式地图未大量导入这些记录。
- 游戏 100% 完成清单的竞速金牌、店铺项目次数和标记钞票累计额存在报道差异，分别标为争议。各条件一项计一格，独立于实际游戏百分比和本站探索统计。[PowerPyx 首发版统计](https://www.powerpyx.com/gta-6-100-completion-checklist-guide/) · [Push Square PS5 统计](https://www.pushsquare.com/guides/gta-6-100percent-completion-checklist)
- 秘籍页面只列出找到一致方向键证据的项目。补满弹药触发阈值有 20 或 25 枚奖牌两种记录，暂作待核实。本站未在实体主机逐一复验。[PowerPyx](https://www.powerpyx.com/gta-6-all-cheats) · [PC Gamer](https://www.pcgamer.com/games/grand-theft-auto/gta-6-cheats-list/)

## 审核新条目

用游戏证据确认对象和版本，优先核对游戏内名称与地图定位。记录信息来自哪一个具体画面或攻略小节。社区坐标需留上游 ID 与许可，未知坐标保留为空。同类别同名点需核查是否为不同分店或不同可收集物。涉及更新和前置条件时，与旧版记录对照后更新审核日期。提交前运行 `npm run data` 和地图浏览器用例。
