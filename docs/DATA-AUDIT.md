## 数据核查

- 原始社区地图工作使用 GTADB 虚拟网格。图钉采用源地标相对游戏地图中心坐标，转换式为 `x = 16384 + gameX` 和 `y = 16384 - gameY`。地图行列按 `z,y,x` 读取。每瓦片 256×256 原生像素。适用的社区地图范围、裁切和缩放基于固定版本配置。
- 三种 DPR 原生采样通过后仍能在旧的最靠近街区视图看到栅格源本身的模糊，因此地图统一限制到实看可读的 3.75 级。原生高阶瓦片仍用于高 DPR，底图无官方建筑入口精度。东缘已裁去原素材侧栏，外围显示海色。
- V1 点位从旧裁切线性换算至新网格，保留其原有证据精度和使用中的 ID。位移根据旧裁切配置和上游瓦片版本对照得出。新增建筑点位用实际游戏名称和源条目相配，保留范围位置。没有足以把官方/实机画面中单一入口对到同一网格的证据，因此没有把范围圈升级为精确图钉。
- 设施名与游戏的过滤菜单核对 [喷漆维修](https://www.powerpyx.com/gta-6-all-pay-n-spray-locations/)、[改装](https://www.powerpyx.com/gta-6-all-mod-shops-locations/)、[便利店](https://www.powerpyx.com/gta-6-all-convenience-stores-locations/)及[武器店](https://www.powerpyx.com/gta-6-all-ammu-nation-gun-stores-locations/)。同一来源的镜像不计独立坐标证据。
- 完整攻略按开始、具体操作、成功信号、完成和奖励审核。部分第一章中间任务在主线解锁后可并行，文章的前后导航按收录的攻略顺序排列。
- 自动审计审查 582 个结构化站内入口及关联、48 个去重外部证据 URL，以及缺正文或仅有外链的详情。构建中的 `audit:links -- --network` 把 HTTP 状态、超时、拒绝访问、404/410 分开记录。技术上能访问的来源仍需编辑核对其实际支持的字段。
